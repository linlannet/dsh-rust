# 脱敏规则

录制后必须执行，并在 `meta.json` 的 `redacted` 中登记。

## 必须替换

- API Key、Bearer Token、Cookie、Session 票据：替换为 `<redacted>`。
- 邮箱、手机号、真实姓名：替换为 `user@example.com`、`13800000000`、`张三`。
- 本机绝对路径：替换为 `/workspace/demo` 或 `C:\\demo`。
- 内网地址、数据库连接串、端口：替换为 `127.0.0.1` 和 `8090`。

## 归一化

- 随机 ID 替换为稳定占位：`agent-1`、`sess-1`、`run-1`、`msg-1`、`tc-1`、`evt-1`。
- 时间戳替换为固定值，但保持先后顺序。
- 耗时字段替换为固定值，或从比对中剔除。

## 禁止

- 不要为了“跑通”而删除字段或改错误码。
- 不要把整段模型输出替换成空字符串；保留语义，只替换敏感片段。
- 不要提交真实生产 dump。
